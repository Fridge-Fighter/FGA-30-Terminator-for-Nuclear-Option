# FGA-30-Terminator-for-Nuclear-Option

This plugin adds the FGA-30 from the old QoL mod as a standalone plugin.
This plugin works by cloning the FGA-57 Anvil and putting a new turret mesh onto it - same principle as QoL.
The code for the turret mesh has been extracted from the qol_1.1.8.1.dll so this plugin can work on its own, a copy of QoL is NOT required to be present.
Nothing, except the code for the Terminator, has been taken from QoL. This plugin is safe and has no other function except adding said vehicle.
The zip file available under "Releases" contains both the .dll file, which simply gets dropped in the plugins folder to install the mod, as well as the source code for transparency.
The coding for this plugin was done by Grok - this is vibecoded. 


I am not involved with any of the developers of the Primeva 2082 team. The plublication of this plugin was approved and allowed by kingwixly, as another mod release containing this vehicle is not planned.
Primeva 2082 takes credit for the creation of this vehicle as well as the coding work for it. I am simply publishing this standalone plugin to keep the vehicle available to players in the future.
